# Схема електрощита

- `shchyt.drawio` — схема у форматі draw.io (diagrams.net), 2 сторінки:
  1. **Однолінійна схема** — апарати та припущений порядок з'єднань (мережа + генератор).
  2. **Розміщення в щиті** — вигляд спереду, як апарати стоять на DIN-рейках.
- `gen_drawio.py` — скрипт, яким згенеровано файл (`python3 gen_drawio.py shchyt.drawio`).

Відкрити: https://app.diagrams.net → File → Open from → Device.
Для Visio: у diagrams.net File → Export as → VSDX.
