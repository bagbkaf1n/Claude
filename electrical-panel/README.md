# Схема електрощита

- `shchyt.drawio` — схема у форматі draw.io (diagrams.net), 3 сторінки:
  1. **Однолінійна схема** — апарати та припущений порядок з'єднань (мережа + зарядна станція).
  2. **Розміщення в щиті** — вигляд спереду, як апарати стоять на DIN-рейках.
  3. **Монтажна схема** — апарати як модулі; дроти сховані за апаратами, на клемах — нумеровані маркери + таблиця з'єднань.
- `scheme-animation.html` — анімована однолінійна схема: шлях струму залежно від мережі та положення SA1 (відкрити в браузері).
- `scheme-animation.gif` — запис демо-сценарію (30 с).
- `gen_drawio.py` — скрипт, яким згенеровано файл (`python3 gen_drawio.py shchyt.drawio`).

Відкрити: https://app.diagrams.net → File → Open from → Device.
Для Visio: у diagrams.net File → Export as → VSDX.
